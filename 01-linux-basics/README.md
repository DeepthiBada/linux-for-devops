# Linux Basics

This folder covers the fundamental Linux concepts required for system administration, DevOps, and cloud engineering.

## Topics Covered

- Introduction to Linux
- Linux File System
- Terminal Basics
- File and Directory Navigation
- File and Directory Management
- Absolute vs Relative Paths
- Wildcards
- Hidden Files
- Command Help and Documentation
- Practice Exercises

## Learning Objectives

After completing this section, you will be able to:

- Navigate through the Linux file system
- Create, copy, move, and delete files and directories
- Understand the Linux directory structure
- Use command-line tools efficiently
- Work confidently with the Linux terminal
